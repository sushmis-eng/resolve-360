# Resolve 360 — AI Customer Escalation Platform

This Space builds the React frontend and FastAPI backend into one web application.

- API: `/docs`
- Demo fallback classification runs without an API key (clearly labeled).
- To enable LLM triage, add `OPENAI_API_KEY` under Space Settings → Variables and secrets → Secrets.
- This is a demo. SQLite data on free ephemeral storage may be lost after restart.
- Do not submit real customer banking data.
